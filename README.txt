Blur + Tones - installable app

1. Host this folder over HTTPS (e.g. GitHub Pages: new public repo -> upload all files ->
   Settings > Pages > Deploy from branch "main" / root).
2. On your phone, open the URL in Chrome -> menu (⋮) -> "Install app" / "Add to Home screen" -> Install.
3. Samsung: Settings > Lock screen > Shortcuts -> pick "Tones" for the left or right shortcut.
Works offline after first open. In your gallery, Share -> Tones opens the photo straight in the app.
